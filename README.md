# Underwater Robotics - MATE ROV Competition

## Project Overview
This project was developed as part of an underwater robotics club, where we designed and built a remotely operated vehicle (ROV) capable of basic underwater movement and control. The robot was built using an Arduino-based system and integrates multiple components such as motors, sensors, and a control interface.


## Key Features
* Multi-directional movement using multiple thrusters
* Arduino-based control system
* Integration of basic sensors for environmental feedback
* Modular design allowing for iterative improvements

## Tech Stack
* **Language:** C++
* **Hardware:** Servo Motors, Embedded Microcontrollers 

## Repo Structure

* `code/` – Arduino programs for controlling the robot
* `images/` – Photos of the robot and development process
* `docs/` – Reports and technical documentation
